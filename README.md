This project analyzes a synthetic ride-sharing dataset created for learning purposes, focusing on understanding ride patterns, fare behavior, and user trends using Python. It involves data cleaning, preprocessing, and exploratory data analysis with tools like Pandas, NumPy, Matplotlib, and Seaborn. The study examines relationships between ride distance, fare amount, traffic conditions, day of the week, and user ratings to uncover meaningful insights. Key findings show that fares generally increase with distance, traffic significantly influences pricing and ride distribution, and user ratings vary based on ride conditions. The project demonstrates foundational data analysis skills and suggests future improvements such as using real-world data, applying machine learning for fare prediction, and building interactive dashboards for deeper insights
