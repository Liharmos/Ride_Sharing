# Ride_Sharing
<h1>About</h1>

    <p>
        This project explores a synthetic ride-sharing dataset using Python. 
        It focuses on understanding ride patterns, pricing behavior, and user trends 
        through data analysis and visualization. The goal is to practice real-world 
        data handling and gain insights using Python libraries.
    </p>
<hr>
    <h2>Features</h2>
    <ul>
        <li>Analysis of fare vs ride distance</li>
        <li>Impact of traffic conditions on rides</li>
        <li>Ride distribution across weekdays</li>
        <li>Visualization using Matplotlib & Seaborn</li>
        <li>Basic grouping and aggregation with Pandas</li>
    </ul>
